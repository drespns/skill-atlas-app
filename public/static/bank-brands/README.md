# Logos de bancos y brokers

Coloca aquí los logos de cada entidad. El nombre del archivo debe coincidir con la **clave** del catálogo en `packages/expense-core/src/wealth-account-brands.ts`.

Formato preferido: **SVG** (`imagin.svg`). También se intenta `.png` si el SVG no carga.
