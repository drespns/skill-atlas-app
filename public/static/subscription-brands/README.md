# Logos de suscripciones

Coloca aquí los logos de cada servicio. El nombre del archivo debe coincidir con la **clave** del catálogo en `packages/expense-core/src/subscription-brands.ts`.

Formato preferido: **SVG** (`spotify.svg`). También se intenta `.png` si el SVG no carga.

## Claves disponibles

| Archivo | Servicio |
|---------|----------|
| `spotify.svg` | Spotify |
| `movistar-plus.svg` | Movistar+ |
| `netflix.svg` | Netflix |
| `disney-plus.svg` | Disney+ |
| `amazon-prime.svg` | Prime Video |
| `youtube-premium.svg` | YouTube Premium |
| `apple-one.svg` | Apple One / iCloud |
| `chatgpt.svg` | ChatGPT |

| `crunchyroll.svg` | Crunchyroll |
| `dazn.svg` | DAZN |
| `dropbox.svg` | Dropbox |
| `notion.svg` | Notion |
| `cursor.svg` | Cursor |

Al guardar una suscripción, el nombre se compara con los alias del catálogo y se asigna el logo automáticamente. También puedes elegir la marca manualmente en el modal.
